ACS DEMOGRAPHIC DATA
====================
Place the 5-Year Census ACS files for this case in this folder:

1. *_data_long.csv
   - Long-format ACS table containing:
     [table_id, line, label_full, stat_type, value, year, cbsa_code, geography_name]

2. *_codebook.csv
   - ACS variable definitions for the corresponding data tables.

3. *_wide_by_code.csv
   - Wide-format ACS profile tables (DP02, DP03, DP04, DP05).
